# DDL_to_GDrive
Transfer files downloaded using DDL [Direct Download Link] to your Google Drive.

Basically, Google Colab downloads the file for you and uploads it to your drive. Initially created with the intention to mainly use it to download files in non-resumeable host server. Thought it would be useful for people without stable and fast internet connection wanting to pause and resume these files when downloading. Regardless, it will work with any DDL.

Storage is basically your Google Drive's storage limit. Have fun :)
